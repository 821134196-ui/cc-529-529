# 后厨刀具流转管理系统

按刀具编号登记刀型、工位、领用人、刃口状态和磨刀周期；班次开始领刀、结束逐件清洗核对归还，
磨刀后由**另一个人**复检锋利度与刀身完整性。SQLite 存逐刀流转，刃口照片存本地，
提醒在进程内运行，扫码枪由模拟适配器提供事件。

零第三方依赖，仅需 Python 3.10+。

## 启动

```bash
python3 run.py              # 自动建库、播种（含缺口案例）并打开浏览器
python3 run.py --reset      # 清空后重新播种
python3 run.py --port 9000  # 换端口
```

默认地址 http://127.0.0.1:8765/

## 内置演示案例

| 刀号 | 案例 |
|---|---|
| D-003 砍刀 | 刃口 4mm **缺口**，待修隔离（黄黑条纹槽），禁止发放 |
| D-004 水果刀 | **刀柄松动**，待修 |
| D-008 片刀 | **错放工位**（凉菜间的刀出现在热菜间 B-06） |
| D-009 水果刀 | **遗失冻结** |

## 功能页面

- **工位刀架图**：按刀架真实槽位（A-01…C-06）排列；刀型用 SVG 轮廓 + 文字共同表示；
  空槽=缺件，黄黑条纹=待修，红框=遗失，黄底=磨刀/错放。
- **领还扫码**：扫码枪扫一次自动判领用/归还；右侧固定突出**缺件 / 未复检 / 超期**；
  可播放模拟扫码序列。
- **保养排程**：磨刀周期表 + 磨刀/复检工单，支持上传本地刃口照片。
- **异常隔离**：缺口、松柄、遗失、错放单独登记与解除。
- **流转台账**：逐刀流水，点刀号看完整流转链与**最后接触人**。

## 业务规则（均有后端强校验）

1. **独占领用**：同一把刀不能同时被两名厨师领用，第二人扫码返回 409。
2. **冻结/隔离**：状态为待修、遗失的刀不能重新发放；待复检刀也不能发放。
3. **复检职责分离**：磨刀者不能批准自己的复检，必须另一位同事；复检驳回 → 隔离待修。
4. **跨班交接**：班次跨日时未归还的刀逐刀留痕移交，领用人不变；有刀未还时禁止直接关班。
5. **全程追溯**：领、还、异常、磨刀、复检、交接全部写入 `movements`，最后接触人取最近一条。

## 测试

```bash
python3 -m unittest discover -s tests -v
```

覆盖：独占领用、跨班交接（未还刀移交 + 关班拦截）、复检权限（本人拒绝/驳回隔离/未复检冻结）、
遗失冻结与找回、缺口松柄隔离、错放工位、磨刀超期标记、最后接触人追溯。

## 结构

```
run.py                     一条命令启动
kitchen_knives/
  db.py        SQLite schema、逐刀流转、派生标记
  service.py   领域规则（领还/磨刀/复检/异常/交接）
  events.py    事件总线、模拟扫码枪、进程内保养提醒线程
  web.py       JSON API + SSE + 静态页 + 照片存取
  seed.py      演示数据（缺口等案例，无依赖生成示意刃口 PNG）
  static/      前端（不锈钢白 / 炭灰 / 安全黄）
data/                      knives.db 与 photos/（运行时生成，已 gitignore）
```
